# P2 — L0 concept scope

## One-page structure

Hero → capability framing → three service pathways → verified workshop specifications → practical process → telephone CTA.

## Content truth boundary

Public BVA facts only: location, founding-year claim, broad services, selected published machine dimensions and public phone/address. Any completion claim, customer logo, certification, project image, testimonial, automated quote, form or email workflow is excluded.

## Acceptance criteria

- One H1 and logical section headings.
- Desktop and 390px responsive layout.
- One unique hero image, clearly a generic concept atmosphere image internally recorded.
- No false form, submitted state, backend, tracking or external publishing.
- Bottom section adds a specific direct-contact route and business context rather than repeating a generic CTA.
