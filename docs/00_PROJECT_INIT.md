# P0 — Project initiation

- **Level:** L0 local-only concept preview.
- **Goal:** demonstrate a clearer industrial capability, trust and direct-contact presentation for BVA Metal Fabrications.
- **Audience:** industrial, mining, food-industry and general fabrication buyers needing an initial capability assessment.
- **Core action:** call the existing public office number.
- **In scope:** one static responsive page; public facts; one original concept image; no data collection.
- **Out of scope:** RFQ submission, drawings/uploads, quote calculation, CRM, email sending, tracking, production deployment and customer-approved assets.
- **Critical unknowns:** real RFQ workflow; authoritative business email; customer asset permission; formal buyer priorities.
- **Acceptance:** local desktop and ~390px browser review; all links use `tel:` only; no internal/governance text exposed; no client imagery or false claims.
